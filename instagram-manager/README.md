# دایرکت‌یار (DirectYar)
نسخه اولیه مدیریت فارسی اینستاگرام با مرورگر داخلی، Chrome، میان‌بر دایرکت، پاسخ‌های آماده و فهرست چند حساب.

- بدون API متا و بدون سرور
- رمز عبور در کد برنامه ذخیره نمی‌شود
- تعامل مستقیم کاربر با سایت اینستاگرام؛ قابلیت‌ها تابع محدودیت‌های سایت است
- انتشار و ارسال خودکار در نسخه فعلی وجود ندارد

Build: Java 17 / Gradle 8.7 / Android SDK 35 `gradle assembleDebug`
