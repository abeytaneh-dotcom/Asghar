# دایرکت‌یار ۱.۱ – نسخه آزمایشی اندروید

اپ شخصی فارسی برای دسترسی به Instagram و Meta Business Suite با مرورگر داخلی اندروید؛ بدون API یا ذخیره رمز ورود در سرور اختصاصی.

## امکانات
- ورود و نمایش صفحات اصلی وب اینستاگرام (از جمله دایرکت، پروفایل، انتشار و نظرات)
- بارگذاری مستقیم دایرکت، تازه‌سازی، دکمه برگشت، نمایش عنوان متناسب با آدرس واقعی
- جواب‌های آماده قابل افزودن، ویرایش، حذف و کپی از داخل صفحه گفتگو
- میان‌بر حساب‌ها و امکان حذف حساب از فهرست محلی (این عملکرد به معنای تعویض نشست واقعی نیست)
- بازکردن صفحات در Chrome در صورت بروز محدودیت WebView
- پاک‌کردن کوکی‌های داخلی با انتخاب کاربر

## حریم خصوصی و محدودیت‌ها
ورود از سایت Instagram/Meta انجام می‌شود. رمز عبور توسط پنل اختصاصی دریافت یا ارسال نمی‌شود. در مرورگر داخلی کوکی‌ها در ذخیره‌سازی استاندارد Android WebView نگهداری می‌شوند. ارسال خودکار دایرکت، پاسخ خودکار، استخراج پیام‌ها و انتشار خودکار از طریق API در این نسخه انجام نمی‌شود. چنانچه نسخه وب اینستاگرام صفحه‌ای را محدود کند، دکمه Chrome در دسترس است.

## نصب کنار نسخه ۱.۰
شناسه بسته نسخه آزمایشی ۱.۱ برای نصب کنار نسخه قبلی `ir.beytaneh.directyar.next` انتخاب شده است. در نتیجه اپ قبلی و داده‌هایش حذف نمی‌شود؛ اما کوکی‌های WebView به اپ جدید منتقل نمی‌شوند. در حالت Chrome از نشست ورود خود Chrome استفاده می‌شود.

## ساخت
JDK 17، Android SDK 35 و Gradle 8.7:

```bash
gradle assembleDebug
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`. نسخه آزمایشی با کلید Debug امضا می‌شود، نه کلید انتشار Play Store.
