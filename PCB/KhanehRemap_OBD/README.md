# KhanehRemap OBD PCB

KiCad PCB design workspace for the KhanehRemap OBD automotive interface.

## Known project context
- Board target: 48 mm × 48 mm
- Interfaces: OBD-II, CAN, K-Line
- Previous project name: `KhanehRemap_OBD_RevE_FINAL_COMPLETE`
- Previous KiCad PCB file: `KhanehRemap_OBD_FINAL.kicad_pcb`

## Git workflow
All PCB work for this project is kept on branch `kicad-pcb`.
KiCad source files (`.kicad_pro`, `.kicad_sch`, `.kicad_pcb`) and fabrication outputs can be versioned here.

## Current state
The previous KiCad source archive is not yet present in this repository. Once the source files are added, schematic review, ERC/DRC cleanup, placement, routing, and fabrication outputs can continue from GitHub.
