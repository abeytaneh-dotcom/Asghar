افزونه یا ابزار جادویی برای همه سایت‌ها وجود ندارد. تصاویر، فونت، اسکریپت، پاسخ سرور و ساختار CSS باید جداگانه بررسی شوند.

بهینه‌سازی تصاویر

ابعاد مناسب، فشرده‌سازی، فرمت درست و lazy loading برای تصاویر پایین صفحه می‌توانند حجم انتقال داده را به شکل محسوسی کم کنند.

JavaScript و CSS غیرضروری

کتابخانه‌ها و فایل‌های بلااستفاده زمان بارگذاری و پردازش را بالا می‌برند. حذف یا تأخیر منابع کم‌اهمیت معمولاً اثر بیشتری از تغییرات ظاهری دارد.

فونت و کش مرورگر

فونت‌های زیاد یا بارگذاری نامناسب می‌توانند نمایش متن را عقب بیندازند. کش درست نیز از دانلود تکراری فایل‌های ثابت جلوگیری می‌کند.
