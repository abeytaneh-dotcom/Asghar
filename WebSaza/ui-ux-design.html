طراحی UI UX برای محصولی که کاربر می‌فهمد

تجربه کاربری خوب یعنی کاربر بدون آموزش اضافه بتواند مسیر اصلی را پیدا کند. رابط کاربری نیز باید همین مسیر را واضح‌تر کند.

UX Flowتعریف مسیرهای اصلی کاربر
UI Systemاجزای هماهنگ و منظم
Prototypeبررسی قبل از توسعه نهایی

UX قبل از رنگ و ظاهر است

قبل از طراحی بصری باید مشخص شود کاربر چه هدفی دارد و از چه مسیرهایی عبور می‌کند. معماری اطلاعات و ترتیب مراحل پایه تجربه کاربری هستند.

UI باید یک سیستم منسجم باشد

دکمه‌ها، فرم‌ها، فاصله‌ها و تایپوگرافی باید قواعد مشترک داشته باشند. این هماهنگی هم استفاده را ساده‌تر می‌کند و هم توسعه محصول را سریع‌تر می‌کند.

طراحی برای حالت‌های واقعی

خطا، بارگذاری، خالی بودن داده و موفقیت عملیات بخشی از تجربه هستند. محصول فقط در حالت ایده‌آل طراحی نمی‌شود.
