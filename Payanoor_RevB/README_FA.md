# پایانوُر – KiCad Rev B (2026-11-16)
این شاخه فقط برای تحویل نسخه‌های **قابل ویرایش در KiCad 10** ساخته شده است. **هیچ‌یک به‌عنوان طرح تأییدشده ساخت نهایی کارخانه معرفی نمی‌شوند.**

## دریافت و بازکردن
فایل ZIP موردنظر را دانلود کنید و Extract کنید. در KiCad 10 از File > Open Project فایل `board.kicad_pro` داخل پوشه استخراج‌شده را باز کنید. برای مشاهده PCB مستقیماً `board.kicad_pcb` را باز کنید. `fp-lib-table`، `sym-lib-table` و پوشه `parts.pretty` را کنار فایل اصلی نگه دارید.

| پروژه | فایل | وضعیت آزمایش |
| --- | --- | --- |
| شاخه LED ۲۸۳۵ | `LED_strip_90x8_KiCad.zip` | ابعاد ۹۰×۸ میلی‌متر، شش LED 6V و هرکدام مقاومت ۱۰ اهم 1210؛ فقط مس جلو، بدون via، ERC=0 / DRC=0. فوت‌پرینت LED موقت است. |
| کنترلر فلاشر | `ATmega8_10_stick_controller_KiCad.zip` | شماتیک ATmega8، پنج MOSFET، کلید سه‌حالته، پتانسیومتر و ISP، کد HEX؛ ERC=0 / DRC=0 با **دو لایه و ۴۷ via**؛ شرط یک‌رو و مکانیک نهایی کارفرما تأیید نشده است. |
| مبدل ۷٫۵V/9A | `Buck_7p5V_9A_reference_KiCad.zip` | طرح آموزشی/مرجع XL4016، ۷٫۵ ولت؛ **۱۶۰×۱۰۵ میلی‌متر**، دو‌رو و با فوت‌پرینت XL4016 دست‌فرم‌دهی موقت؛ **برای ساخت نهایی مناسب نیست**. |

## شرایط سفارش
ورودی ۹ تا ۳۶ ولت، خروجی ۷٫۵ ولت، ۶۰ LED 6V/1W نوع 2835 با ۶۰ مقاومت جداگانه ۱۰Ω SMD (حداقل ۰٫۵W) در ده شاخه ۶ عددی؛ ۵ حالت کنترلیِ جفتی در سه موقعیت OFF/FLASH/ROTATE، ابعاد شاخه ۹۰×۸، کنترل ATmega8. توان نظری LEDها ۵۴ وات و مجموع تلفات مقاومتی ۱۳٫۵ وات، خروجی ۶۷٫۵ وات با فرض Vf دقیقاً ۶V و If=۱۵۰mA.

## توقف تولید
تأیید رنگ و دیتاشیت LED خریداری‌شده، ابعاد واقعی پدها، منبع ۷٫۵V/9A با حفاظت گذرا تا ۶۰V، تناسب با بدنه و برد تک‌رو، بازبینی گلوگاه‌های جریان، دما و نویز، تأیید فنی کارخانه و آزمایش فیزیکی کامل لازم است. قبولی نرم‌افزاری ERC/DRC **اعتبارسنجی عملکرد و دما نیست**.
