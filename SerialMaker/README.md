# Khaneh Remap Serial Maker

ابزار ویندوز برای ثبت دستگاه‌های ESP32-C3 و تولید Serial + QR.

## نسخه تست
- خواندن Chip ID / MAC از ESP32-C3 با esptool
- تولید سریال به شکل KR-YY-XXXXXX
- جلوگیری از ثبت تکراری همان برد
- ذخیره بانک دستگاه‌ها در devices.csv
- ساخت QR برای هر دستگاه
