# Khaneh Remap ECU Station - Windows Demo

نسخه نمایشی فارسی نرم‌افزار تستر/پروگرامر ECU.

## امکانات نسخه دمو
- رابط کامل فارسی و RTL
- صفحه شروع با «حالت دمو» و «اتصال به دستگاه»
- داشبورد زنده
- کنترل RPM، TPS و دمای آب
- شبیه‌سازی انژکتورها، کوئل‌ها، پمپ و فن
- داده زنده
- اسیلوسکوپ CKP/CMP/Injector/Ignition
- تست خودکار مرحله‌ای
- DTC آزمایشی
- محیط پروگرامر با READ/BACKUP/WRITE/VERIFY شبیه‌سازی‌شده
- برچسب واضح DEMO برای جلوگیری از اشتباه با ECU واقعی

## ساخت
GitHub Actions خروجی Windows x64 self-contained single-file EXE می‌سازد.
