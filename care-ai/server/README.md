# Care AI Server

این پوشه را در مسیر پیشنهادی `https://achinu.ir/careai/` آپلود کنید.

1. مطمئن شوید PHP 8+، PDO_SQLite و cURL فعال است.
2. به `admin.php` بروید و کاربر مدیر بسازید.
3. در بخش پیامک، IPPanel/FarazSMS Token، شماره فرستنده و Pattern Code را وارد کنید.
4. مقدار API Base URL را برابر URL همین پوشه بگذارید.
5. کاربران بعد از OTP در حالت غیرفعال ساخته می‌شوند و باید توسط مدیر فعال شوند.
6. هر شماره، Patient ID و Device ID یکتا است. برای انتقال به گوشی دیگر ابتدا از پنل «آزادسازی گوشی» بزنید.
7. آپدیت APK را در همان پنل با Version Code بالاتر آپلود کنید.
