# Khaneh Remap SmartOBD Diagnostic v3

نسخه جدید هسته عیب‌یابی برای ESP32-C3 و رابط خانه ریمپ.

## بخش‌های فعال عیب‌یابی
- مشخصات ECU
- خواندن و پاک کردن DTC
- پارامترهای زنده
- Reset ECU در ECUهایی که سرویس را پشتیبانی می‌کنند
- صفحه کیلومتر: RPM، سرعت، دمای آب، سطح سوخت
- هشدار مستقل کمبود آب

## ارتباط خودرو
- CAN OBD-II: 500/250 kbit/s
- K-Line: ISO 9141-2 و ISO 14230/KWP
- Mode 01 / 03 / 04 / 09
- BLE بین ESP32-C3 و رابط کاربری

## بخش‌های فعلاً غیرفعال
جعبه ابزار ECU، تعریف سوئیچ و ریموت، تنظیم کیلومتر، اتصال OBD مستقل، تست باتری و تنظیمات در UI با پیام «به زودی...» نمایش داده می‌شوند.

Firmware source is under `firmware/KhanehRemap_SmartOBD_Diag_v5/`.

این شاخه برای تست سخت‌افزار واقعی ایجاد شده و قبل از استفاده نهایی باید روی ECUهای هدف خودرو به خودرو اعتبارسنجی شود.
