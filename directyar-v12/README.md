# دایرکت‌یار ۱.۲ — DirectYar Android

نسخه جدید بدون API متا و با رابط فارسی برای مدیریت نیمه‌دستی اینستاگرام.

## قابلیت‌ها
- مرورگر داخلی اینستاگرام و Meta Business Suite، امکان باز کردن در Chrome
- دسترسی سریع به دایرکت، پاسخ‌های آماده و فهرست حساب‌ها
- پیشنهاد پاسخ محلی مبتنی بر قواعد و کلیدواژه، بدون ارسال متن به سرور
- نمایش پیش‌نویس، امکان ویرایش و **تأیید صریح** پیش از کپی
- ذخیره پاسخ‌های پیشنهادی به‌عنوان الگو
- میان‌بر به بخش کامنت‌های Meta و راهنمای انتخاب سربرگ Instagram comments
- آماده‌سازی و ذخیره محلی کپشن، کپی و انتقال دستی به بخش Content در Meta

## امنیت و محدودیت‌ها
این برنامه پیام‌ها را به‌صورت خودکار نمی‌خواند، هیچ پیامی ارسال نمی‌کند و پست یا استوری را مستقل منتشر نمی‌کند.
کاربر باید متن پیام را وارد کند، پاسخ را تأیید کند و آن را در صفحه رسمی اینستاگرام ارسال کند.
ورود از طریق وب‌سایت رسمی انجام می‌شود. کوکی‌های مرورگر داخلی تحت Android WebView ذخیره می‌شوند.
دسترسی‌های حساس یا کلید API در برنامه وجود ندارد. پیشنهاد پاسخ، مدل AI مولد نیست.

## نصب و تفاوت با نسخه ۱.۱
برنامه دارای applicationId مستقل ir.beytaneh.directyar.v12 است. برای جلوگیری از خطای امضای نسخه
۱.۱ آزمایشی، این نسخه **در کنار نسخه قبلی** نصب می‌شود؛ وضعیت ورود و پاسخ‌های محلی نسخه قبلی خودکار منتقل نمی‌شوند.

## ساخت

gradle --no-daemon assembleDebug
